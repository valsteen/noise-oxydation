# Repository guidance

- This Rust 2024 workspace has four current owners: `codec` converts G.711 μ-law, `dsp` owns fixed-frame signal processing, `pipeline` owns packet and call lifecycle, and `ffi` exports the C boundary. The `go` module owns the safe per-call Go wrapper. Keep dependencies directed from FFI to pipeline to codec/DSP.
- The public path is 8 kHz mono and consumes 160-byte packets. Preserve ordered valid samples, the whole-packet process result, one-time finish with its final valid count, and full reset.
- Keep processing and finish free of allocation and blocking synchronization. Recheck `crates/pipeline/tests/no_alloc.rs` when changing those paths.
- The C ABI uses valid caller-owned storage and serial raw-handle access. Go `Call` serializes its own lifecycle, including `Close`; recheck `crates/ffi/tests/no_alloc.rs` and Go lifecycle tests when touching the bridge. Go/cgo scheduling is not a hard real-time guarantee.
- `go/pcm.go` is the optional `dsp.Processor`-shaped compatibility surface for 160 normalized PCM samples. It converts through G.711, returns owned slices, and needs `Finish` at call end. Keep the direct `Call` API at the μ-law packet boundary as the lower-overhead path. Neither surface depends on the original Go module; test codec roundtrips and adapter/direct output parity when changing conversion.
- The quiet intro is a five-second default configured at runtime. The conservative mode keeps its observed 128-sample frame cutoff and baseline bypass and requires at least 256 learning samples. The experimental mode uses an 80-sample hop with the same quiet-intro assumption and requires at least 320 samples to learn one complete real-input frame; keep docs and tests aligned with both schedules.
- `Pipeline::new`, C `no_create`, and zero-value Go `Config.Mode` remain conservative. The experimental lower-delay mode is selected per call in the same binary. Preserve conservative output byte-for-byte and keep experimental quality and CPU claims tied to measured fixtures.
- SPP-MMSE is the default of three public noise estimators. Conservative MCRA and minimum estimation use a fixed 50-frame history; experimental mode uses 80 frames to retain the 800 ms horizon. MCRA protects sustained narrowband speech after window turnover while the simple minimum remains a lower-envelope estimator. Tonal gain follows Log-MMSE for every selection. Keep each call's estimator and tonal buffers private to its DSP instance, and document chosen formulas separately from unverified Go behavior.
- `tools/render_how_it_works.rs` owns the guide and its four day/night SVGs. Regenerate them after changing the guide source and run its `--check` mode before returning a candidate.
- Run the locked workspace build, tests, Clippy with pedantic warnings denied, and nightly rustfmt check before returning a candidate.
