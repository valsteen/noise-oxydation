The reference is pinned to [`cfc7520a0625`](https://github.com/sghaida/noise-cancelation/commit/cfc7520a0625da90e4ad4699541a6ffe98e7c637). Entries distinguish a demonstrated documentation error from a possible implementation defect. Go source was inspected only to establish that this revision has no shipped top-level MCRA pipeline; no Go implementation source was copied into Rust.

## Component comparison

The [pinned Go revision](https://github.com/sghaida/noise-cancelation/commit/cfc7520a0625da90e4ad4699541a6ffe98e7c637) has no shipped top-level MCRA pipeline. The probe composed its public μ-law decode, high-pass, STFT, MCRA, Log-MMSE, tonal, ISTFT, and encode stages. It used the same 24,000 μ-law bytes as the [Rust sustained-speech test](../crates/pipeline/tests/streaming.rs): one second of quiet stationary noise, then two seconds of uninterrupted 250/500 Hz voice and an 875 Hz tone.

The metric projects the 250 Hz sine over samples 16,000–24,000. The composed Go stages retained 68.6% of the input fundamental. Rust candidate `72db720` retained about 8% before the MCRA correction; the current Rust test requires at least 60%. This is component evidence, not a shipped Go end-to-end comparison or exact numerical parity. Revisit formula parity with a documented Go pipeline or independent black-box evidence.
